BIR Reset Pass Keys

A client cannot reset its BIR records (System Hard Reset while BIR records exist, or the AGT reset) without a one-time pass key signed here. The client app shows a request code; you inspect it, enter a reference, and issue a key bound to that installation, device, action and request. The key expires, works once, and works offline on the client.

Admin authentication

The admin key stays in this page's memory only; it is never saved in the browser.

2. Check the request

3. Send this pass key to the client
