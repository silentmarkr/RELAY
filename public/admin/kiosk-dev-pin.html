Kiosk Developer PIN

Ang PIN na ito ay para sa lahat ng client. Kailangan ito ng OMNIKiosk (Counter > Settings) para palitan ang Uri ng negosyo (restaurant, sari-sari, serbisyo, atbp.). Ikaw lang ang may alam; hindi ito ipinapadala sa mga client; naka-hash dito sa RELAY. Kapag pinalitan mo, agad itong magiging bago sa lahat ng client.

Admin authentication

Nasa memory ng page na ito lang (at sa sessionStorage ng tab, gaya ng ibang admin page).

Mag-connect muna gamit ang admin key.
