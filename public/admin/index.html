💾 Backup / Restore▾

Full snapshot ito ngayon (v3) — kasama na ang lahat ng persisted data (devices, unlocks, history, fingerprints, pricing/feature overrides, download codes, build history, atbp.), hindi lang yung 4 na field dati. Bagama't naka-Postgres na ang karamihan nito (hindi na basta-basta nawawala sa redeploy), extra safety net pa rin ito kung sakaling magkaproblema ang database mismo o mag-delete ka ng service/domain. Download-in pa rin periodically (lalo na pagkatapos ng bagong unlock/customer) at itago sa ligtas na lugar.
The auto-download filename includes a date/time stamp (e.g. relaybackup07260130.json = July 26, 1:30 AM — your browser's LOCAL time), so each allow creates a new file instead of overwriting the last one. These stay in your Downloads folder as your backup history.

🚀 Publish a New Update (build + publish in one click — no Termux/curl required)▾

One button, two steps: (1) builds a fresh omnipos-client.zip from the latest code in your repo, and (2) immediately announces this new version/changelog to existing clients (they'll see it in their "Check for Update"). If the build fails, the version publish will NOT proceed.
If you fill in a Target Installation ID, the "update available" notice will go ONLY to that device — other clients won't see it until you clear the target or make the same version global (blank Target ID). Note: the actual zip file is still shared/single — this only targets who sees the notice, it's not a hard download block.

ℹ️ How these numbers are computed

MRR comes from active licenses on allowed devices: monthly plans count at full price, yearly plans at price ÷ 12, lifetime, free or admin-activated licenses add nothing (admin-activated value is shown separately on each card).
Tokens spent comes from the Omni Token ledger, so it adds up over time. It does not include licenses granted by an admin or approved by OTP without tokens being spent.
All-time (latest purchase) only keeps the latest payment per device, so renewals replace the older amount.
Omni Token sales counts paid purchases only. Months follow Asia/Manila time.
