💾 Backup / Restore

Walang persistent disk ang Render free tier — nawawala ang allowed devices, naka-unlock na features, at history sa bawat git push/redeploy, at mawawala LAHAT kung ide-delete mo ang service/domain. I-download ang backup paminsan-minsan (lalo na pagkatapos ng bagong unlock/customer) at itago sa ligtas na lugar.
Ang filename ng auto-download ay may petsa/oras stamp (hal. relaybackup07260130.json = July 26, 1:30 AM — LOCAL na oras ng browser mo), kaya iba-ibang file ito kada allow (hindi nag-o-overwrite sa isa't isa). Ito ang mananatili sa Downloads folder mo bilang history ng mga backup.
