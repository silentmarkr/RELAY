💾 Backup / Restore

Walang persistent disk ang Render free tier — nawawala ang allowed devices, naka-unlock na features, at history sa bawat git push/redeploy, at mawawala LAHAT kung ide-delete mo ang service/domain. I-download ang backup paminsan-minsan (lalo na pagkatapos ng bagong unlock/customer) at itago sa ligtas na lugar.
Ang filename ng auto-download ay may petsa/oras stamp (hal. relaybackup07260130.json = July 26, 1:30 AM — LOCAL na oras ng browser mo), kaya iba-ibang file ito kada allow (hindi nag-o-overwrite sa isa't isa). Ito ang mananatili sa Downloads folder mo bilang history ng mga backup.

🚀 Mag-publish ng Bagong Update (build + publish sa isang click — dito na lang, walang Termux/curl kailangan)

Isang button na ito para sa DALAWANG hakbang: (1) gagawa ng bagong omnipos-client.zip mula sa pinaka-bagong code sa repo mo, at (2) i-a-announce agad ang bagong version/changelog na ito sa mga existing na kliyente (makikita nila sa "Check for Update" nila). Kung mabigo ang build, HINDI ita-tuloy ang pag-publish ng version.
Kung punan mo ang Target Installation ID, SA KANYA LANG mapupunta ang "may bagong update" na notice na ito — ibang kliyente, hindi makikita hangga't hindi mo pa siya i-clear o hindi mo pa ginawang global (blangko ang Target ID) ang parehong version. Paalala: ang aktwal na zip file ay iisa pa rin/shared — targeting lang ito ng "sino ang makakakita ng notice", hindi hard block sa pag-download.
