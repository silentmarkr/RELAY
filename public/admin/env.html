🔐 ENV Vault

Dito mo ilalagay ang mga key/secret ng RELAY kapalit ng Environment ng Render. Naka-hide ang values bilang default; pindutin ang 👁 para makita ito sandali (15 segundo, may audit log, HTTPS lang). Ang ENV ng Render ang nananaig; ang vault ay pumupuno lang ng mga variable na wala sa Render. Kailangan ng restart para mabasa ito ng lahat ng function. Ang RELAY_ADMIN_KEY, RELAY_PRIVATE_KEY_PEM at (para sa database copy) ang DATABASE_URL ay dapat manatili sa Render.

📥 Import (Render .env format)

I-paste ang laman ng .env (parehong format ng Render: NAME=value bawat linya, may # comments, may quotes, at multi-line sa loob ng quotes) o pumili ng file. Makikita muna ang preview (walang value na ipinapakita), tapos piliin kung alin ang ise-save. Puwede rin ang JSON {"NAME":"value"}.

📤 Export

Para ilipat o i-backup ang mga variable. Ang laman ay may secrets: itago ang file at burahin pagkatapos gamitin. Hindi kasama ang RELAY_PRIVATE_KEY_PEM at RELAY_ENV_MASTER_KEY.

🩺 System check

Sinusubukan ang mga value na ginagamit ngayon: format, magkakaugnay na variable, at totoong koneksyon sa database, Cloudflare AI, Google AI, email, Telegram, payments at mga download link. Walang email/message na ipinapadala at walang value na ipinapakita.
