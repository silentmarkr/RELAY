📲 App Updates (APK)

Dito mo ina-upload ang lahat ng APK na dina-download ng mga app mula sa RELAY: ang OmniPOS Native app mismo, ang 5 companion apps (Settings → Install other apps → Get latest online) at ang WorkShiftData.

I-upload lang dito ang bagong .apk: kusa nang binabasa ng RELAY ang package, versionCode at versionName sa loob nito, kaya wala ka nang ibang ilalagay. Sa app (Settings → Check for app update, o Install other apps → Get latest online), makikita ng user kung mas mataas ang versionCode (nasa app/build.gradle; dapat mas mataas sa dati) kaysa sa naka-install, at madi-download at mai-install nila ito. Naka-save ang APK sa database (hindi sa disk ng Render, na nabubura kapag nag-redeploy). Mahalaga: tatanggapin lang ng Android ang update kung pareho ang signing key ng bagong APK at ng naka-install na app: laging i-build gamit ang parehong keystore/computer.
