💳 Cloud Backup Pricing
OmniPOS Unlock Relay — ground truth for pricing

This is the ONLY place Cloud Backup pricing lives. OmniPOS installations fetch it from GET /relay/pricing on their own (with a local fallback cache in case this RELAY is unreachable) — nothing about price is hardcoded in OmniPOS anymore. Changes here take effect for every installation the next time they refresh (usually within the hour). Looking to edit Pro Theme / Module pricing instead? That has its own separate Feature Pricing page.

Module Subscriptions

RBAC Management and Multi-Branch Dashboard are subscriptions too (converted from a one-time purchase) — flat monthly/yearly pricing, no tiers. A subscription that lapses stays working for a 7-day grace period before it locks (this buffer is not editable here — it's intentionally the same for both, hardcoded server-side).
