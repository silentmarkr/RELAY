⚡ Omni AI — Provider Status & Upgrade Tiers

Ang Provider status ay awtomatikong nagla-lock kapag naubos ang Cloudflare daily quota (10k neurons) — agad na tatanggihan ang AI requests hanggang 00:00 UTC (8:00 AM PH), walang hintay at walang nasisingil na credits. I-Clear ito pagkatapos mag-upgrade sa Workers Paid. Ang daily limit ay NEURONS kada araw (hindi na bilang ng tanong). Tatlo ang tier: Base (libre, hati ng Total daily capacity sa Max clients / divider), Plus at Pro (binibili gamit ang Omni Tokens, ≈ ₱1 bawat token, valid hanggang katapusan ng buwan). Lalabas ang upgrade sa Help page ng client kapag naabot niya ang daily/monthly limit. Ang daily neurons ay 0 = walang limit.
