ℹ️ How the Omni AI tiers work (read first)
Several tiers, two providers — the mapping is fixed:
• Free — clients without an Omni AI subscription ➜ Cloudflare Workers AI. Text only (no images/files/model picker). Has its own small monthly credits and daily neurons; all Free clients share one free Cloudflare pool (10,000 neurons/day).
• Base — clients with an Omni AI subscription ➜ Google (Gemini). Included free with the subscription. Daily neurons = Total daily capacity divided by Max clients (divider).
• Lite / Plus / Pro / Business — upgrades for subscribed clients, bought with Omni Tokens (≈ ₱1 per token, valid until the end of the month) ➜ Google (Gemini). Gemini Flash can be locked to a single tier.
Free never falls back to Google, and Base/Plus/Pro never fall back to Cloudflare — so one can never use up the other quota. When a provider is exhausted, the request is rejected right away (no credits are charged). Every daily limit is in NEURONS per day; 0 = no limit. Setup: see the 🧭 Setup checklist below.
